Source Definitions

DefiLlama5 endpoints

Base URL: https://api.llama.fi/protocol/near-intents

  • GET /protocol/near-intents (TVL)
  • GET /summary/fees/near-intents?dataType=dailyFees|dailyRevenue|dailyHoldersRevenue
  • GET /overview/dexs/near-intents (may 500)
  • GET /coins/near (price history)
  • GET /v2/historicalChainTvl/Near (chain TVL)
BigQuery (crypto_near_mainnet_us)5 endpoints

Base URL: https://console.cloud.google.com/bigquery

  • transactions (block_date, signer_account_id, status)
  • receipt_actions (action_kind, args.deposit, receipt_receiver_account_id)
  • ft_events (contract_account_id, affected_account_id, delta_amount, cause)
  • ft_balances_daily (account_id, liquid, staked, contract_account_id)
  • blocks (total_supply, block_date)
NEAR Intents Explorer API3 endpoints

Base URL: https://explorer.near-intents.org/api/v0

  • GET /transactions (1 req/5s, JWT required)
  • Cursor pagination via lastDepositAddress + lastDepositMemo
  • Filters: statuses, startTimestampUnix/endTimestampUnix (non-inclusive)
revenue.near.org3 endpoints

Base URL: https://revenue.near.org

  • JS-rendered dashboard only (no API)
  • Manual reference values in data/reference/revenue_near_org.yaml
  • Three revenue wallets: fefundsadmin, buybacks.multisignature, 1csfundsadmin

Statistical Method (D9)

Transforms

  • • Stationary transforms: log-differences (log x_t - log x_t-1)
  • • Primary frequency: weekly (ISO weeks)
  • • Minimum n = 52 weekly observations
  • • Missing weeks dropped, never interpolated

Inference

  • • Stationary block bootstrap CIs (1000 resamples, block length 10)
  • • Benjamini–Hochberg FDR across all lags tested
  • • Partial correlation controlling for BTC/ETH returns
  • • Effect size + CI + n reported (never p-value alone)

Structural Breaks

  • • Pre/post 2026-02-23 (buyback programme start)
  • • Exclude 14 days post 2026-10-01 (Omni exploit)
  • • Results reported for each subsample

Concentration

  • • Gini coefficient, HHI, top-k share
  • • Dimensions: addresses, contracts, chains, tokens
  • • Quarterly trend (linear slope)

Known Limitations

  • • Accounts ≠ humans: "Active accounts" = distinct signer addresses. Multi-sig, exchanges, bots inflate counts.
  • • Addresses ≠ people: Multi-chain individuals = multiple addresses. "Unique sender addresses" used, never "people".
  • • Confidential flows: Intents CONFIDENTIAL_INTENTS deposit/recipient types not fully visible.
  • • Explorer coverage: 1Click API documents only its own coverage; other integrators may differ.
  • • Price conversion: NEAR↔USD conversion introduces noise; revenue in NEAR is primary.
  • • Timing mismatch: Fees accrue per swap; sweeps to protocol wallets happen later with variable lag.
  • • Buyback ≠ burned: Onchain evidence shows bought-back NEAR held, not burned. Revenue.near.org claims "permanently removed".
  • • BigQuery quota: Free tier 1 TB/month limits backfill; revenue wallet outflows pending quota reset.

Data Modes (D2)

Live

Pipeline ran against real APIs with credentials just now. Shows retrieval timestamp.

Snapshot

Committed real aggregated data from earlier live run. Persistent amber banner with snapshot date.

Synthetic

Generated fixtures for unit tests only. Loud red banner + watermark on every chart. Never default.

Every JSON artifact carries data_mode. Pipeline refuses to combine artifacts with different modes.
